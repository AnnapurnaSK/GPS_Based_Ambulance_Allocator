Project Snapshot

  • GPS routing prototype uses OSRM travel duration.
  • Driver allocation is based on available fleet records.
  • Admin operations are protected with JWT auth.
  • Dispatch emails are sent to both patient and driver.

For Patients

Request an ambulance from a single form.

The public flow accepts your contact details and coordinates, searches for the best available ambulance, and returns the matched driver details when the backend succeeds.

For Admins

Manage the fleet from the protected dashboard.

Admins can log in, review driver records, add new ambulances, update live status and location, or remove outdated records.

System Logic

Allocation favors the fastest reachable ambulance.

The current backend inspects available drivers and compares route duration before choosing the best match for the emergency request.
